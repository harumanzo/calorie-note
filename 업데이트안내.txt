칼로리노트 1.1 업데이트

기존 GitHub 저장소에 이 ZIP 안의 파일을 덮어쓰기 업로드하고 Commit changes를 누르세요.
중요: 저장소를 삭제하거나 새로운 저장소를 만들지 마세요. 기존 앱 주소와 기록을 유지하려면 동일 주소에서 업데이트해야 합니다.
아이폰 앱을 종료 후 다시 열어 변경사항을 확인하세요. 이전 버전이 보이면 인터넷 연결 상태에서 Safari 앱 주소를 새로고침하고 잠시 후 홈 화면 앱을 다시 여세요.
기존 기록과 음식은 삭제되지 않도록 호환 처리했습니다. 다만 업데이트 전 기록·백업에서 JSON 백업을 저장해 두세요.
음식 관리에서 완제품의 영양정보 기준을 1팩·1개·1통 등으로 선택하고 포장지 값을 입력하세요. 식단 기록에서 그 음식을 선택하면 수량 기본값이 1로 설정됩니다.
