칼로리노트 v1.2 업데이트

1. 아이폰에서 기존 앱의 JSON 백업 파일을 보관하세요.
2. ZIP 파일을 풀고 내부 파일 전체를 기존 GitHub 저장소 루트에 업로드하여 덮어쓰세요.
3. GitHub Pages 배포가 완료된 후 Safari에서 사이트를 새로고침하세요. 설치형 앱에 업데이트가 늦게 반영되면 Safari에서 사이트 주소 뒤에 ?v=12 를 붙여 방문 후 다시 실행하세요.
4. 기존 음식 목록과 식단 기록은 동일한 localStorage 키(calorie_note_v1)를 사용하므로 그대로 유지됩니다.
5. 기존 앱의 기록이 보이지 않으면 새로 등록하지 말고 JSON 백업을 가져오세요. 복원은 현재 데이터를 교체합니다.

새 기능: 최근 기록에서 다시 추가, 일회성 간식 빠른 입력, 선택적 음식 목록 저장. 기존 100g/1팩/1개 단위 등록 유지.

주의: GitHub Pages 주소가 바뀌면 브라우저 저장소도 달라질 수 있습니다.
